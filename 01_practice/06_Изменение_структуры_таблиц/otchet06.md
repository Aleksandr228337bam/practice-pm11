# Отчет по практической работе №6: Изменение структуры таблиц

## 1. Цель работы
Изучить DDL-команды для модификации структуры базы данных (`ALTER TABLE`) и удаления таблиц (`DROP TABLE`), ознакомиться с ограничениями СУБД SQLite при изменении типов данных и выполнить дополнительные задачи модуля.

## 2. Ход выполнения работы и анализ результатов

### Эксперимент 1. Удаление таблицы
Была выполнена команда полного удаления таблицы из базы данных:
```sql
DROP TABLE IF EXISTS product;
```
* **Результат:** Запрос успешно выполнен без ошибок (`Execution finished without errors`). Таблица `product` и все её данные были полностью стерты.

### Эксперимент 2. Попытка изменения удаленной таблицы
При последующей попытке добавить новое поле в эту же таблицу с помощью команды:
```sql
ALTER TABLE product ADD ...
```
* **Результат:** СУБД SQLite вернула ошибку: `Execution finished with errors. Result: no such table: product`. Это подтверждает, что объект был успешно удален на предыдущем шаге и больше не существует в базе данных.

## 3. Решение дополнительных задач модуля

### Задача на поиск ошибки
* **Запрос с ошибкой:** 
  ```sql
  ALTER TABLE product ALTER COLUMN price TYPE REAL;
  ```
* **Объяснение ошибки:** Данный запрос вызовет синтаксическую ошибку в SQLite. В отличие от некоторых других СУБД (например, PostgreSQL), облегченная СУБД SQLite имеет встроенные ограничения и **не поддерживает** прямое изменение или переименование типов отдельных столбцов через конструкцию `ALTER COLUMN`. Чтобы изменить тип данных столбца в SQLite, необходимо полностью пересоздать таблицу с новой структурой.

### Задача на предсказание результата
* **Сценарий:** В таблице `product` изначально находится 5 строк. Выполняется запрос на добавление нового текстового столбца:
  ```sql
  ALTER TABLE product ADD COLUMN new_col TEXT;
  ```
* **Запрос проверки:** 
  ```sql
  SELECT COUNT(*) FROM product;
  ```
* **Ответ:** После добавления нового столбца общее количество строк в таблице никак не изменится. Запрос `SELECT COUNT(*)` вернет результат **5**. Команда `ALTER TABLE ... ADD COLUMN` изменяет исключительно схему (структуру) таблицы, добавляя новое поле во все существующие записи со значением по умолчанию `NULL`, но не удаляет и не добавляет сами строки.
