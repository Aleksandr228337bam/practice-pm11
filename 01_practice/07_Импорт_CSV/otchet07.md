# Отчет по практической работе №7: Импорт CSV

## 1. Цель работы
Изучить механизмы и инструменты импорта внешних структурированных данных из файлов формата CSV в таблицы СУБД SQLite, а также разобрать особенности сопоставления типов данных при импорте.

## 2. Результаты выполнения заданий
В рамках практической работы был осуществлен импорт демонстрационного набора данных из файла формата `.csv` в соответствующую таблицу базы данных. Процесс прошел успешно, структура данных сохранена. Скриншот, подтверждающий успешный импорт и корректное отображение записей в DB Browser, прикреплен в текущей папке.

## 3. Решение дополнительных задач модуля

### Задача на поиск ошибки
* **Проблема:** В результирующей таблице после импорта оказалось 100 строк вместо ожидаемых 50.
* **Объяснение ошибки:** Данная аномалия чаще всего возникает из-за **повторного выполнения процедуры импорта данных** поверх уже существующих записей в таблице. Если перед запуском повторного импорта не была произведена предварительная очистка целевой таблицы (с помощью команд `DELETE FROM имя_таблицы;` или пересоздания через `DROP TABLE`), утилита импорта просто допишет новые 50 строк из файла в конец таблицы к уже имеющимся 50 строкам.

### Задача на предсказание результата
* **Сценарий:** Выполняется импорт CSV-файла, содержащего числовые значения цен, в два разных столбца со специфичными типами данных: `TEXT` и `REAL`.
* **Ответ:** 
  * В столбце с типом данных **`TEXT`** все импортированные числовые цены примут строковый формат (будут считываться СУБД как обычный текст/последовательность символов).
  * В столбце с типом данных **`REAL`** числовые значения автоматически сконвертируются и запишутся как числа с плавающей точкой (дробные числа), что позволит в дальнейшем корректно проводить над ними математические и агрегатные операции.
