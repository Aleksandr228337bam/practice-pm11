## 3. Решение дополнительных задач модуля

### Задача на поиск ошибки
* **Запрос с ошибкой:** 
  ```sql
  SELECT * FROM product WHERE price > 100 OR price 50 AND category_id = 1;
  ```
* **Объяснение ошибки:** Данный запрос вызовет ошибку синтаксиса (Syntax Error). В условии фильтрации после оператора `OR` для поля `price` пропущен оператор сравнения перед числом 50. СУБД не может распарсить конструкцию `price 50`. Для исправления ошибки необходимо явно указать оператор сравнения, например: `price > 50` или `price < 50`.

### Задача на предсказание результата
* **Тестовый запрос:** 
  ```sql
  SELECT * FROM product WHERE name LIKE 'M%' ORDER BY price LIMIT 2;
  ```
* **Исходные данные:** В базе имеются товары: `Хлеб (40)`, `Молоко (60)`, `Мыло (80)`, `Морковь (30)`.
* **Пошаговый разбор выполнения запроса СУБД:**
  1. **Фильтрация (`WHERE name LIKE 'M%'`):** СУБД отберет только те товары, название которых начинается на заглавную букву «М». Товар `Хлеб` отсеивается. Остаются: `Молоко (60)`, `Мыло (80)`, `Морковь (30)`.
  2. **Сортировка (`ORDER BY price`):** Оставшиеся товары выстраиваются по возрастанию цены:
     * `Морковь` (30)
     * `Молоко` (60)
     * `Мыло` (80)
  3. **Ограничение выборки (`LIMIT 2`):** Из отсортированного списка отсекается всё, кроме первых двух строк.
* **Итоговый ответ:** Запрос вернет ровно две строки с товарами: **Морковь (30)** и **Молоко (60)**.
