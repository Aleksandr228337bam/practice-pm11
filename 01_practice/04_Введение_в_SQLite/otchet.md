## 3. Решение дополнительных задач модуля

### Задача на поиск ошибки
* **Код с ошибкой:** 
  ```sql
  CREATE TABLE student (id INTEGER, fio TEXT, birth TEXT);
  ```
* **Вопрос:** Почему `id` не будет автоматически увеличиваться?
* **Ответ:** Чтобы столбец автоматически увеличивался (автоинкрементировался) при вставке новых строк, он обязательно должен иметь ограничение `PRIMARY KEY AUTOINCREMENT` (или просто `INTEGER PRIMARY KEY`). Без этого SQLite будет считать `id` обычным числовым полем и не будет автоматически присваивать ему новые последовательные значения.

### Задача на предсказание результата
* **Запрос:** 
  ```sql
  SELECT sqlite_version();
  ```
* **Ответ:** Данный запрос вернёт таблицу, состоящую из одной строки и одного столбца, в которой будет указана текущая версия движка SQLite, используемая в программе DB Browser (например, `3.42.0`).

### Продвинутый случай (Работа с типами данных)
* **Вопрос:** Для чего предназначено поле типа `BLOB`?
* **Ответ:** Поле типа `BLOB` (Binary Large Object) предназначено для сохранения бинарных данных большого объема — например, изображений, аудиофайлов, документов или любых других двоичных файлов непосредственно внутри таблиц самой базы данных.
